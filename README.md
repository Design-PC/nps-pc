# Plataforma de Pesquisa NPS Corporativa Prime Control

Este repositório documenta a estratégia, experiência, analytics e especificação técnica para a nova Pesquisa NPS B2B da Prime Control.

## Objetivo

Transformar a pesquisa atual, hoje percebida como um formulário corporativo estático, em uma experiência digital moderna, rastreável e orientada a conversão, preservando integralmente as perguntas aprovadas.

## Princípios

- Nenhuma pergunta deve ser alterada, reescrita, removida ou enviesada.
- A experiência deve reduzir percepção de esforço.
- A jornada deve ser mensurável do convite à conclusão.
- A solução deve priorizar clientes ativos B2B e respondentes executivos ocupados.
- Analytics comportamental é parte central do produto, não um complemento.

## Stack Recomendada

- Frontend: Next.js, TypeScript, Tailwind, Shadcn UI
- Banco: Supabase ou PostgreSQL
- CRM e envio: HubSpot
- Analytics: Microsoft Clarity, PostHog, GA4
- Dashboard: Power BI ou Metabase
