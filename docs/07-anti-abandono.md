# 07 - Estratégia Anti-Abandono

## Objetivo

Reduzir desistência antes do início, durante o preenchimento e nas etapas finais, sem alterar perguntas nem influenciar respostas.

## Estratégias Prioritárias

### 1. Link Com Token Único

Cada contato recebe um link individual, sem login.

Benefícios:

- Reduz fricção.
- Permite personalização.
- Permite retomada.
- Conecta comportamento ao CRM.

### 2. Pré-preenchimento De Identificação

Usar HubSpot para preencher:

- Nome
- E-mail corporativo
- Empresa
- Área
- Cargo

Benefícios:

- Menos digitação.
- Menor abandono inicial.
- Dados mais confiáveis.

### 3. Autosave

Salvar progresso a cada resposta e troca de etapa.

Benefícios:

- Reduz ansiedade.
- Permite retomada.
- Evita perda de dados parciais.

### 4. Retomada Inteligente

Ao retornar, levar o usuário ao ponto em que parou.

Estados:

- Não iniciou: landing.
- Iniciou: retomar etapa.
- Concluiu: confirmação.

### 5. Progressão Visível

Mostrar:

- Etapa atual.
- Quantidade total de etapas.
- Percentual aproximado.
- Mensagem de última etapa.

### 6. Cadência De Lembretes Por Comportamento

Não usar o mesmo lembrete para todos.

Cadência:

- Dia 0: convite inicial.
- Dia 3: lembrete para abriu e não respondeu.
- Dia 5: lembrete para clicou e não iniciou.
- Dia 6: lembrete para iniciou e abandonou.
- Dia 8: reforço para contas estratégicas.
- Dia 10: último lembrete curto.

### 7. Monitoramento Mobile

Executivos frequentemente abrem no celular. A experiência mobile deve ser tratada como prioridade.

Métricas:

- Completion rate mobile vs desktop.
- Tempo por etapa mobile.
- Rage clicks mobile.
- Drop-off em escalas.

### 8. Redução De Ansiedade Textual

Campos abertos devem receber microcopy neutra:

```text
Se preferir, responda em uma frase objetiva.
```

Isso reduz bloqueio sem alterar a pergunta.

## Alertas Operacionais

Criar alertas para:

- Conta estratégica sem abertura após 3 dias.
- Conta abriu e não clicou.
- Conta iniciou e abandonou.
- Detrator em conta estratégica.
- Comentário textual com indício de risco.
